# GridSpace

GridSpace is a lightweight digital sketch board built with React and TypeScript, designed for quick idea generation, brainstorming, and simple digital drawing. The project focuses on an intuitive user experience, clean interface, and essential drawing tools that make it feel like a modern, functional whiteboard.

## Features

- Freehand drawing with a pen tool
- Eraser support for removing strokes cleanly
- Custom color selection from a color picker
- Adjustable brush width
- Undo and redo actions
- Clear canvas option
- Responsive layout for desktop and smaller screens
- Clean, modern UI inspired by productivity and design tools

## Tech Stack

- React
- TypeScript
- Tailwind CSS

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open the local URL shown in the terminal to use the app.

## Build for Production

```bash
npm run build
```

## Notes

This app is intentionally designed to be simple, fast, and visually clean, making it a strong example of a polished front-end project that balances functionality with a professional appearance.
